ADAS Calibration program

Program overview

Effective April 8, 2025, State Farm® began a national rollout of its calibration program with the Select Service program in five phases. State Farm entered into an agreement with Opus IVS as the preferred provider to supply Select Service repair facilities and State Farm staff appraisers with accurate information on which types of calibration operations are necessary based on estimated vehicle repairs.

State Farm requires the use of ADAS Map™, the ADAS calibration software system for use on Select Service and State Farm staff estimates (including potential total loss vehicles) as part of this program.

State Farm has established a part code table that includes calibration entries for use on repair estimates. Select Service repair facilities and State Farm staff appraisers utilize ADAS Map to assist in determining necessary calibration operations and enter those operations onto repair estimates using the part code table.

Repairers are free to choose their diagnostic tool and calibration service provider; however, the amount billed for calibrations should not exceed the price State Farm would have paid per their part code table.

State Farm has also identified local mobile/car-side service providers that perform calibrations at State Farm’s part code table pricing. These mobile/car-side providers that work in specific zip codes may be found on the Diagnostic Locator.

Opus IVS locator

To find mobile and/or car-side providers in your area to assist with needed calibration services, please visit the Diagnostic Locator.

Upon visiting the site, users may enter the collision repair facility’s location in the search bar. Users may view results for all mobile/car-side providers within the same zip code and may utilize the provided contact details to schedule an appointment for calibrations.
