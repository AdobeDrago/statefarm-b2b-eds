Certificate holder & error

Certificate holder

Enter your company's name and address as the Certificate Holder.

Once you have entered all of the required fields (Name, Address, City, State, Zip and Country), click on CONTINUE to standardize the address or you can return to the Insurance Inquiry application by clicking on CANCEL.

Error messages

If you fail to enter required information, the system provides one or more error messages.

  • The insurance policy you are looking for could not be located with the information you have given us
  • Name is a required field.
  • Address is a required field.
  • City is a required field.
  • State/Province is a required field.
  • Zip/Postal Code is a required field.
  • Zip/Postal Code must be numeric.
  • Zip/Postal Code must be 5 or 9 positions.
  • Country is a required field.
