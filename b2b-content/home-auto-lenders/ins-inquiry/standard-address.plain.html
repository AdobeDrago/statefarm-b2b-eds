Address standardization

Standardization

Once the Certificate Holder’s name and address have been entered, the system will try and standardize the address.

A standardized address ensures proper mailing of the notice if cancelled or reinstated. You may choose however, to create the certificate with the address you desire.

Please remember to review the standardization results. If you entered the wrong address, use the Back button to try again.

Non-standardized address

When the address cannot be standardized, you still have the opportunity to provide the address you have entered. Click on the CONTINUE button to proceed.

If you entered the wrong address, use the Back button to try again.
