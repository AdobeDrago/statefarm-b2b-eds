997 functional acknowledgement electronic file

For every 811 Auto EDI file sent from State Farm, a 997 Functional Acknowledgement electronic file is required to be returned.

997 Functional Acknowledgement

ST*997*0001~Transaction Header – to indicate the start of a transaction set and to assign a control number
AK1*CI*1~Functional Group Response
Ak2*811*0005~Transaction Set Response Header
AK3*NM1*37~Data Segment Note – to report errors in a data segment and to identify the location of the data segment
AK4*1*98*7~Data Element note - To report errors in a data element and to identify the location of the data element
AK5*E*5~Transaction Set Response Trailer - to acknowledge acceptance or rejection and to report errors in a transaction set
AK9*A*2*2*2~Functional Group Response Trailer - to acknowledge acceptance or rejection of a functional group and report the number of included transaction sets from the original trailer, the accepted sets, and the received sets
SE*67*0001~To indicate the end of a transaction set and to provide a count of the transmitted segments
