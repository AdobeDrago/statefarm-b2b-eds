Errors and corrections

The Application Advice returns errors and corrections to the lender in response to an individual Mortgage Record Change.

  • 824 Data Format : ISA*00**00**ZZ*STFMSF00053*12* 8186665767INS*030206*1652*U*00400*000000007*Y*P* — Description: This is the envelope segment for the 824.
    • 000000007 is the unique number for this envelope
  • 824 Data Format : GS*MG*STFM SF00053* 8186665767INS*20030206*1652*7*X*004010~ — Description: This is the group segment for the 824.
    • 7 is the unique number for this group.
  • 824 Data Format : ST*824*0001~ — Description: This is the transaction segment for the 824.
    • 0001 is the unique number for this transaction.
  • 824 Data Format : BGN*00*TS266*20030206*165201** 1800~ — Description: This is the beginning segment for the 824.
    • 00 Original
    • 1800 the unique number from the originating 266..
  • 824 Data Format : N1*IN*State Farm Mutual Automobile Insurance Company*FI*370533100~ — Description: This is the sender of the 824.
    • IN Insurer
    • FI Federal Tax ID
    • 370533100 is the Tax ID of the sender
  • 824 Data Format : N1*SJ*INSURANCE TRACKING CO*FI*123456789~ — Description: This is the receiver of the 824.
    • SJ Service Provider
    • FI Federal Tax ID
    • 123456789 is the Tax ID of the receiver.
  • 824 Data Format : N1*LV*A - ONE MORTGAGE*FI*123456789~ — Description: This is the lender (new or current) for which the changes were made.
    • LV Lender
    • FI Federal Tax ID
    • 123456789 is the Tax ID of the lender.
  • 824 Data Format : REF*3L*A1~ — Description: This is the branch code of the lender, which, along with the Tax ID, creates a unique electronic signature.
    • 3L Branch Identifier
  • 824 Data Format : OTI*IR*LD*020941499*******266~ — Description: This is the start of the individual exceptions for each loan.
    • IR Exception
    • IC Correction
    • LD Loan Number
  • 824 Data Format : REF*IG*13P374667~ — Description: The policy number from the 266 if valid, otherwise, the corrected policy number from the insurer.
    • IG Policy Number.
  • 824 Data Format : REF*66*13P374667~ — Description: If the original policy number provided in the 266 was invalid.
    • 66 Incorrect Policy Number
  • 824 Data Format : REF*TV*HOME~ — Description: The policy type is returned in the 824 if corrected. Valid policy types are:

    HOME, PPTHO, PPUHO, FLOOD, COTHR, RDP, DFIRE, EQKP, FARM, BOAT, RCUP, PPMBH, PPCHO, PPART, BOP. The policy type will be returned in the 824 if corrected.
    • TV Line of Business
  • 824 Data Format : REF*NF*25143~ — Description: The company code is returned in the 824 if corrected.
    • 25143 SF Fire
    • 43419 SF Lloyds
    • 25151 SF General
    • 10739 SF Florida
  • 824 Data Format : DTM*540****D8*20031015~ — Description: The policy expiration date will be returned in the 824 if corrected or this could be the Coverage Cease Date if the policy is cancelled.
    • 540 Policy Expiration Date
  • 824 Data Format : LM*AD~ — Description: The identification of the code source.
    • AD ACORD
  • 824 Data Format : LQ*ABS*100~ — Description: This policy error code.
    • 100 Policy not found
    • 110 Non pay cancel
    • 111 Insured cancel
    • 112 Company cancel
    • 115 Corrected
    • 180 Renewal Forthcoming
    • 181  Policy Type Not Supported
    • 182 State Farm Payment Plan
  • 824 Data Format : The next policy goes here by repeating the OTI - LQ segments.
  • 824 Data Format : SE*17*0001~ — Description: SE01 is the number of segments. SE03 is the same number as ST02.
  • 824 Data Format : GE*1*7~ — Description: GE03 is the same number as GS06.
  • 824 Data Format : IEA*1*000000007~ — Description: IEA02 is the same number as ISA12.
  • 824 Data Format :

    *Interchange receiver for test is SF00014 and interchange receiver for production is SF00053
